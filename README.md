# CS188 Artificial Intelligence Projects

This repository showcases my implementations and solutions for various projects undertaken during the **CS188: Introduction to Artificial Intelligence** course. Each project delves into fundamental AI concepts, providing practical experience in building intelligent systems.

![image](https://github.com/user-attachments/assets/52a1c7b9-3603-4b28-b83a-2e9e59478cee)


## Projects Overview

1. **Decision Tree**
   - Constructed decision tree models to perform classification tasks.
   - Implemented algorithms to handle both categorical and continuous data.

2. **Neural Network**
   - Developed neural network architectures for pattern recognition.
   - Trained models using backpropagation and gradient descent techniques.

3. **Reinforcement Learning (RL)**
   - Applied reinforcement learning algorithms to solve decision-making problems.
   - Implemented Q-learning and policy iteration methods.

4. **Support Vector Machine (SVM)**
   - Built SVM models for classification challenges.
   - Explored kernel functions to handle non-linear data separations.

5. **Genetic Algorithms**
   - Employed genetic algorithms to optimize complex functions.
   - Simulated evolutionary processes such as selection, crossover, and mutation.

6. **Water Sort Puzzle Solver**
   - Created an AI agent to solve the water sort puzzle game.
   - Utilized search algorithms to find optimal solutions efficiently.

## Repository Structure

- Each project resides in its respective directory, containing:
  - **Code**: Source files implementing the AI algorithms.
  - **Documentation**: Detailed explanations and insights into the project's objectives and methodologies.
  - **Reports**: Analytical reports discussing results, challenges, and learnings.
